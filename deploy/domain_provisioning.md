# 免费域名注册与 TLS 配置（快速落地方案）

注：下面给出的是常见的免费域名获取与 TLS 配置流程。生产环境建议使用正式域名以确保稳定性与长期可控性。

1. 获取一个免费域名（可选方案，适合测试/评估）
- 服务提供商：Freenom（提供 .tk、.ml、.ga、.cf、.gq 等免费域名）
- 步骤概览：访问 Freenom，搜索你想要的域名，选择一个免费后缀，注册账户，确认域名。
- 注意事项：免费域名存在续订/可用性波动，正式生产请考虑购买域名以确保可用性。

2. 将域名绑定到生产服务器的 DNS
- 将域名的 A 记录指向你的服务器公网 IP。
- 如果你的服务器在云厂商（如 AWS、Azure、GCP、DigitalOcean 等）上，请在云端 DNS（或域名注册商提供的 DNS）中配置 LCD。

3. 获取 TLS 证书（Let’s Encrypt）
- 证书邮箱：yix309672@gmail.com（已确认使用）
- 使用 Certbot 与 Nginx 的联合方式获取证书，过程通常为：
  - 安装 certbot 与 nginx 插件
  - 运行 certbot --nginx -d your-domain.com
  - Certbot 将自动配置 Nginx 使用 TLS，并设置自动续期
- 证书路径通常在 /etc/letsencrypt/live/your-domain.com/

4. 部署在生产服务器上的 TLS 配置要点
- Nginx TLS 终止，外部请求走 443，后端服务通过内部网络端口暴露
- 证书续期自动化，确保 60 天内即将到期证书自动续期
- 开放防火墙端口：80/443，内部端口按需要开放（如应用端口）

5. 生产部署与运维注意
- 监控证书续期状态，确保自动续期配置无误
- 保证域名解析生效后再执行证书申请，否则验证失败
- 使用域名访问生产服务，避免使用 IP 直连的测试模式

6. 重要提醒
- 免费域名的稳定性与续期可能存在不可控的风险，请尽量在正式上线阶段使用稳定的正式域名。
- 你也可以选择将前端缓存/静态资源放在 CDN 上，以提升静态资源加载速度和可用性。

此文档为后续补充，正式落地时会把你的域名替换为实际域名，并在部署脚本中自动化执行证书申请。
